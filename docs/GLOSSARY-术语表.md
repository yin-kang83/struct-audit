# 术语表 v0

> 原则：每个词给定义、适用范围、常见误用。术语不统一，体系就不成立。

| 术语 | 定义 | 适用范围 | 常见误用 |
|---|---|---|---|
| 结构 | 账面价值在时间轴上的运动方式 | 后续计量 | 把科目名当结构 |
| 结构假设 | 在现有证据下暂时接受的结构解释 | 审计判断 | 当成事实 |
| 滚存 | A_t = λA_(t−1) + θ_t | 折旧、摊余成本、租赁负债 | 把分配/重设硬套进来 |
| 分配 | D_t = A_0×w_t/Σw | 年数总和法、FIFO、履约进度 | 把分配当滚存 |
| 重设 | A_t = FV_t 或 min(账面,可收回) | 公允价值、减值、持有待售 | 把成本模式当重设 |
| 中断态 | 滚存被事件重置 | 减值、变更、持有待售 | 不处理事件，连续反解 |
| λ | 留存率/延续系数 | 滚存 | 把 λ 当收益率 |
| θ | 当期独立调整项 | 滚存 | 把 θ 和 λ 混在一起 |
| 反解 | 从余额反推参数 | 有确定方程的科目 | 没有数据也硬算 |
| δ（残差） | 反解值 − 声称值 | 参数/结构校验 | 把 δ 当错报 |
| 阈值 | 判断 δ 是否值得追查的界线 | 筛查 | 当准则/重要性 |
| 假设审计 | 先检验结构假设，再算数字 | 审计前置程序 | 直接反解 |
| 底稿 | 可被第三方重算的记录 | 审计 | 只留结果不留过程 |
| 证据分层 | 按可靠性给证据排序 | 案例/判断 | 把管理层说明当强证据 |
| 公开案例 | 可回到公告页码/监管文号 | 写作/教学 | 把综合改编写成公开案例 |
| 综合改编 | 保留结构、去掉身份 | 实务写作 | 不标注 |
| 构造反例 | 为说明逻辑边界而构造 | 方法论 | 伪装成真实案例 |
| 稳定性陷阱 | 稳定可能是被维护出来的 | 审计分析 | 把稳定当安全 |
| 原始假设 | 结构判断的起点 | 全书 | 跳过假设直接算 |
| 恶意 | 法律/道德定性，需明知+故意+行为+掩盖/获利 | 法律/监管 | 从残差推恶意 |

## 使用规则

```text
1 术语第一次出现，给定义
2 同一概念只用一词
3 不把模型词当准则词
4 不把准则词当结论
5 术语变更，记录版本
```
