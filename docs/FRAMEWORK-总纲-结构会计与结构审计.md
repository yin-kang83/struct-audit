# 展开范式：会计、金融与 AI 的结构化重构

> 总纲 v2 / 工作稿
> 副标题：从结构计量到可复核判断
> 说明：v1 只覆盖会计结构；v2 按 89 篇全量库扩成“四板块”。

## 摘要

会计、金融与 AI 三个领域，看似共享“模型”“结构”“智能”等词，实际上各自困在碎片里：会计计量被拆成许多准则与科目，金融定价被拆成许多模型与假设，AI 应用被拆成“记忆结论”与“调用公式”。

本文提出一个统一框架：**展开范式**。从一个公理或定义出发，展开为函数、系数、残差；把会计后续计量写成递推结构，把金融定价写成展开式，把 AI 的知识使用从“记忆结论”改为“展开前提—边界—推导”。在此基础上，本文给出四个板块：会计计量与审计、增益系统、金融学重构、AI 范式；并用 89 篇、47 万字的工作论文库说明：这不是一个想法，而是一条已经展开的研究线。

框架有明确边界：不提出新准则，不统一所有会计，不证明所有金融模型，不替代审计判断，也不把“展开”当成万能钥匙。

**关键词**：展开范式；结构计量；增益系统；金融重构；AI；可复核

## 1 问题：三个碎片化

### 1.1 会计碎片化

```text
折旧：年限/残值/方法
租赁：折现率/租期/续租
摊余成本：实际利率/现金流
PPP：固定/变动收款权
```

每个准则都有自己的公式，但没有一张共同的结构表。

### 1.2 金融碎片化

```text
BSM：几何布朗运动
Heston：随机波动率
Bates：跳跃
久期/凸性：定义式
β/APT：回归系数
```

每个模型都能解释一部分，但概念之间缺少统一的“展开路径”。

### 1.3 AI 碎片化

```text
大模型记忆结论、调用公式
但常剥离前提、边界、推导
导致幻觉、边界滑移、概念漂移
```

三种碎片化，本质相同：

```text
只存结论，不存结构；
只会调用，不会展开。
```

## 2 内核：展开范式

### 2.1 三步

```text
公理/定义 → 展开 → 系数/残差
```

不是“记结论”，是“从公理走到结论”。

### 2.2 会计的结构

```text
A_t = λ·A_(t-1) + θ_t
```

三类：

```text
滚存：λ 固定
分配：D_t=A_0×w_t/Σw
重设：A_t=FV_t 或 min(账面,可收回)
```

### 2.3 金融的展开

```text
久期 = 二项展开中 Δr 的系数
Delta/Gamma/Theta = 伊藤展开中的系数
β = 投影展开中的系数
```

### 2.4 增益项

```text
g = λ − 1
```

```text
g>0：扩张
g=0：维持
g<0：收缩
```

## 3 板块一：会计计量与审计

### 3.1 统一句法

```text
折旧、摊余成本、租赁负债
共享 A_t=λA_(t-1)+θ_t
```

### 3.2 反解与残差

```text
自驱动：r=(A_t+CF_t)/A_(t-1)−1
维持：N=(A_(t-1)−残值)/D_t
耗散：N=2/(1−A_t/A_(t-1))
```

```text
δ = 反解值 − 声称值
```

### 3.3 审计含义

```text
结构识别 → 参数反解 → 残差 → 证据 → 关闭
```

边界：

```text
零残差≠没问题
残差≠错报
残差≠恶意
```

## 4 板块二：增益系统

### 4.1 从个体到系统

```text
个体账户：g=λ−1
复合参数：Γ=(D_g,I_g,S_g)
系统：g_bar、σ_g、ρ
```

### 4.2 三个方向

```text
向内：增益项/信息失真/泡沫识别
向外：六维诊断/边界
向下：摊余成本工具链
```

### 4.3 边界

```text
只进入满足固定递推的计量；
不覆盖公允价值等非递推结构；
不构成对公司整体的判断。
```

## 5 板块三：金融学重构

### 5.1 均值回归公理

```text
价格围绕价值锚点 θ 波动
BSM 是 θ=K 时的特例
```

### 5.2 参考点定价

```text
V_MR = S·N(d1) − θ·e^(−r(T−t))·N(d2)
```

### 5.3 价格结构

```text
波动率微笑、偏度、峰度、期限结构
是同一公理在不同阶矩上的展开
```

### 5.4 证据状态

```text
论文报告：1162 只可转债、9 市场 1647 只股票、沪深300 政策事件
状态：主张强，需复现；不把“论文报告”当“已独立验证”
```

## 6 板块四：AI 范式

### 6.1 从记忆到展开

```text
记忆：存结论，剥离前提
展开：存公理、边界、推导
```

### 6.2 分工

```text
大模型：定性、抽参、解释
代码：确定性计算
底稿：验算、留痕
人：拍板
```

### 6.3 边界

```text
AI 不替人判断
AI 不替代证据
AI 不把“流畅”当“正确”
```


## 9 结论

```text
会计、金融、AI 的共同问题，
不是“模型不够多”，
是“只存结论，不存结构”。

展开范式做的，
是把结论重新接回公理、边界、推导和残差。
```
